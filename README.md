smt-renewal-agent

An ADK ("high-code") agent for BMC Helix that automates populating the SMT (Scenario Modeling Tool) Renewal Input Form from two independent inputs:

a Zara CPQ budgetary quote PDF
a UFR (Up-For-Renewal) Excel export
Background

This is the third architecture tried for this problem, per decisions made in the Sep 10 and Sep 15 Helix client calls:

No-Code (Gemini Enterprise) agent — abandoned. The calculations came out hallucinated / non-deterministic.
Antigravity 2.0 IDE skill — worked better but wasn't viable to ship: it required a per-user local install, and corrections didn't persist across sessions.
High-code ADK agent (this repo) — deterministic calculation logic lives in plain Python (app/tools/smt_calculator.py), not in the LLM. The LLM's job is orchestration (calling tools, asking for confirmation on genuinely ambiguous cases), not arithmetic.
How it works
extract_and_match_quote(pdf_path, xlsx_path, subscription_number) (app/tools/extraction_tools.py) does the following in one Python-only call:
Extracts line items from the quote PDF.
Parses the UFR export, filtered to a single subscription (a real export spans 100+ rows across many customers).
Matches PDF lines to UFR records by product, and classifies each as resolved (quantity increase — one row, existing quantity carried forward plus the PDF's added quantity, Code="a") or ambiguous (PDF qty equals or is less than the existing qty — these require a human decision and are never guessed).
get_customer_tier(account_csn) resolves each product's Customer Tier via app/references/account_csn_tier_mapping.csv, mapped to a real channel_discount_table.csv column through a confirmed-only mapping table. Anything not explicitly confirmed comes back as needs_confirmation, and the agent presents get_valid_customer_tier_columns() (the real column names) rather than inventing plausible-sounding ones.
get_support_rate(support_tier) resolves the real per-tier support rate from app/references/support_rate_table.csv (this is not a flat 20% — it varies by tier and only applies to Perpetual lines).
compute_renewal_line(...) (app/tools/smt_calculator.py) does the actual SMT Part 2 (Renewal) math: license discount, net unit price, total license/support, SDN/Disnet/GSS discount, DATEDIF-style whole-month term calculation, and BRV/TRV/ERV ACV — all in deterministic Python, not generated by the model.
write_renewal_output_xlsx(...) writes the populated Renewal Input Form.
Single combined tool call

Extraction, UFR parsing, and matching are combined into one tool call (extract_and_match_quote) rather than three separate ADK tool calls. A real UFR export is large enough (100+ rows) that letting the model echo the intermediate dataset back as a function-call argument between separate tool invocations causes MALFORMED_FUNCTION_CALL.
